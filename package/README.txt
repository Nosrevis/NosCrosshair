NosCrosshair
============

A crosshair overlay for Windows. It draws a crosshair in the exact centre of your
screen on top of your game. The overlay is click-through, so it never gets in the
way of your mouse. 358 crosshair styles, with your own colour, size, thickness,
gap, outline and opacity.

REQUIREMENTS
  - Windows 10 or Windows 11 (nothing else to install)
  - Play your game in Windowed or Borderless Windowed mode. Exclusive fullscreen
    games draw over every overlay, so the crosshair will be hidden.

INSTALL
  1. Right-click NosCrosshair.zip and choose "Extract All...".
  2. Open the extracted folder and double-click Install.cmd.
     It installs for your user only (no admin needed) and adds Start menu and
     Desktop shortcuts.

  Prefer not to install? Just double-click NosCrosshair.exe. It runs from
  any folder.

"WINDOWS PROTECTED YOUR PC"
  NosCrosshair is not code-signed, so Windows SmartScreen may warn you the first
  time. Click "More info", then "Run anyway".

HOTKEYS (they work while you are in a game)
  F8   Show / hide the crosshair
  F9   Next style
  F7   Previous style

  Closing the settings window hides it to the system tray (next to the clock).
  Double-click the tray icon to open the settings again, or right-click it
  and choose Exit to quit.

SETTINGS
  Saved automatically to %APPDATA%\NosCrosshair\settings.ini

UNINSTALL
  Run Uninstall.cmd from %LOCALAPPDATA%\Programs\NosCrosshair
  (paste that path into the File Explorer address bar). It removes the app,
  its shortcuts and its settings. If you only ran the exe without installing,
  just delete it.
